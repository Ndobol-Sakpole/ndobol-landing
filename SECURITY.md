# Security reports

Please do not put credentials, cancellation codes, or subscriber data in a public issue.

Use GitHub's **Security → Report a vulnerability** for this repository if private reporting is enabled. Otherwise contact the maintainers at **ndobolsesarengan@gmail.com**. Describe the affected route, reproduction steps, and expected impact; use test data you control.

Only the current `main` branch is maintained. There is no promised response-time SLA.

If a credential is exposed, revoke it with the provider and replace it in the deployment settings. Removing a file from the latest commit does not remove it from Git history.
