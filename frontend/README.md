# Frontend

Vanilla HTML templates, CSS, and ES modules. `routes.js` maps URLs to page renderers. The backend renders these templates during local development and the static build.

Indonesian text is the translation key. English copy lives in `locales/`. Browser modules ending in `.client.js` handle navigation, dialogs, the reward calculator, and signup forms.

Edit `styles/hero.css` and `styles/footer.css` for the two scenic sections. Keep responsive backgrounds and character artwork separate. Use the root README for setup and deployment.
